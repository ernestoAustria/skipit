# SKIP IT! website concept - hotlinked photo edition

Static GitHub Pages site with external band-photo URLs hardcoded in CSS.

## Publish
Upload all files/folders to the repository root, then enable GitHub Pages from `main` / `(root)`.

## External images currently used
- https://florianstoellinger.at/info/info/music_files/skipit.jpg
- https://www.kirchdorfer-zement.at/wp/wp-content/uploads/2018/10/Skip-it-350x237.jpg

If either source changes its URL or disables hotlinking, that photo will stop rendering. For production reliability, copy band-owned originals into the repository later.
