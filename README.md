# SKIP IT! website concept
Static GitHub Pages site. Upload the contents to the repository root and enable GitHub Pages from `main` / root.

Band facts and copy are based on skipit.at as retrieved in November 2026. The public site currently links to YouTube and Facebook.

## Photos
The supplied public website exposes photos, but this package intentionally does not republish third-party image files automatically. Add band-owned images under assets/ and replace the `.p1` / `.p2` background declarations with `background-image:url('../assets/your-photo.jpg')` when rights/source files are available.
